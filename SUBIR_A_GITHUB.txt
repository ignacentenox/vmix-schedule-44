PASO 1: CREAR REPOSITORIO EN GITHUB
════════════════════════════════════════════════════════════════════════

1. Abre: https://github.com/new

2. Llena los campos:
   Nombre: vmix-schedule-44
   Descripción: Professional web control panel for vMix automation
   
3. Selecciona:
   • Public (para que cualquiera pueda instalar)
   • NO inicialices con README (ya lo tenemos)
   • License: MIT

4. Click "Create repository"

5. Verás instrucciones. Copia la URL en formato HTTPS (no SSH)
   Ejemplo: https://github.com/tu-usuario/vmix-schedule-44.git


PASO 2: AGREGAR REMOTO Y HACER PUSH
════════════════════════════════════════════════════════════════════════

En tu Mac, ejecuta ESTOS comandos en terminal:

# Navegar al proyecto
cd /Users/ignaciomanuelcenteno/Documents/PROG/2025/CANAL44_RCUPLAY/scheduletv

# Agregar remoto (reemplaza "tu-usuario" con tu username de GitHub)
git remote add origin https://github.com/tu-usuario/vmix-schedule-44.git

# Cambiar rama a main
git branch -M main

# Hacer push
git push -u origin main

# Te pedirá credenciales GitHub:
#   - Usuario: tu_email_github@gmail.com
#   - Password: tu_token_personal_access (no contraseña)


PASO 3: GENERAR PERSONAL ACCESS TOKEN (Si es necesario)
════════════════════════════════════════════════════════════════════════

Si GitHub pide contraseña y no la aceptas:

1. Abre: https://github.com/settings/tokens/new

2. Selecciona:
   ✓ repo (full control of private repositories)
   ✓ admin:repo_hook

3. Click "Generate token"

4. Copia el token (aparece una sola vez)

5. En terminal, cuando pida password, PEGA el token

PASO 5: USAR DESDE TRUENAS (INSTALACIÓN SIMPLIFICADA)
════════════════════════════════════════════════════════════════════════

Una vez en GitHub, simplemente en TrueNAS Shell ejecuta:

¡Una sola línea! El script:
✓ Descarga proyecto desde GitHub
✓ Instala dependencias
✓ Configura Nginx y systemd
✓ Inicia servicios
✓ Listo en http://192.168.192.44/ui/
