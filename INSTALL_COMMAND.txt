Copia y pega en Shell de TrueNAS:
═══════════════════════════════════════════════════════════════════

curl -fsSL https://raw.githubusercontent.com/ignacentenox/vmix-schedule-44/main/install.sh | sudo sh


¿Qué hace?
═══════════════════════════════════════════════════════════════════

✅ Descarga el instalador desde GitHub
✅ Ejecuta con permisos de root (sudo)
✅ Detecta ruta escribible (/opt, /mnt, /var/lib)
✅ Instala Python + Nginx
✅ Configura servicio automático
✅ Inicia la aplicación

Tiempo: ~5-10 minutos


Acceso final
═══════════════════════════════════════════════════════════════════

Abre en navegador: http://192.168.192.44/ui/


Verificar instalación
═══════════════════════════════════════════════════════════════════

systemctl status vmix-schedule-44
systemctl status nginx

tail -f /[INSTALL_DIR]/logs/api.log
