# 🚀 QUICK START - Crear .exe Portátil en Windows 10

## ⚡ 3 Pasos Rápidos

### Paso 1: Descargar Python
- Ve a: https://www.python.org/downloads/
- **IMPORTANTE**: Durante instalación, marca ✅ "Add Python to PATH"
- Instala normalmente

### Paso 2: Ejecutar Builder
**Opción A - Más fácil (Haz doble clic):**
```
BUILD.bat
```

**Opción B - Si BUILD.bat no funciona:**
```
cmd.exe
python build.py
```

Esto tardará 5-10 minutos (se descarga PyInstaller y dependencias)

### Paso 3: Usar el .exe
El ejecutable estará en:
```
dist\vMix_Schedule_44\vMix_Schedule_44.exe
```

- Puedes copiar esta carpeta a cualquier lugar
- Funciona en cualquier Windows 10/11
- No necesita Python instalado

---

## 📋 Requisitos Mínimos

✅ Windows 10 / Windows 11  
✅ Python 3.8+ (se descarga en Paso 1)  
✅ 2GB RAM  
✅ 500MB disco (para compilación)  
✅ Conexión a vMix (http://192.168.192.140:8098)

---

## ❓ Problemas Comunes

**"Python no está instalado"**
→ Descarga desde python.org e instala con PATH

**"BUILD.bat no funciona"**
→ Ejecuta en cmd: `python build.py`

**"Error de permisos"**
→ Ejecuta cmd como Administrador

**"vMix no se conecta"**
→ Verifica IP en BUILD.bat o build.py (línea: VMIX_URL)
