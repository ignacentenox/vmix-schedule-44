📞 SOPORTE - TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

PROBLEMA: "vMix Desconectado"
→ Solución: Verificar que vMix esté en 192.168.192.140:8098
   curl -s http://192.168.192.140:8098/api/ | head -5

PROBLEMA: "No se puede conectar a http://192.168.192.44/ui/"
→ Solución: Verificar que Nginx está corriendo
   sudo systemctl status nginx
   sudo systemctl restart nginx

PROBLEMA: Los eventos no se ejecutan
→ Solución: Verificar AUTO está ON y sincronización horaria
   date (verificar hora en TrueNAS)
   sudo tail -f /opt/vmix-schedule-44/logs/api.log

PROBLEMA: Error de permisos
→ Solución: Ajustar permisos
   sudo chown -R root:root /opt/vmix-schedule-44
   sudo chmod -R 755 /opt/vmix-schedule-44

PROBLEMA: Servicio se reinicia constantemente
→ Solución: Ver logs
   sudo systemctl status vmix-schedule-44 -l
   sudo tail -100 /opt/vmix-schedule-44/logs/api.log
